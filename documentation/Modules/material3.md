# Material 3 Module

The `material3` module provides the table implemented in
[Material 3](https://m3.material.io/) style.

Render the table under `MaterialTheme` to use its colors, shape, typography,
and content color.

See [Getting Started](../Guides/getting-started.md) for a complete table
example and [Table Customization](../Guides/table-customization.md) for ways to
customize its content and interactions.
